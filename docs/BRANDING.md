# Branding

## Name

**GuessNova** combines the simplicity of a number-guessing game with a bright, exploratory “nova” identity.

## Visual concept

The logo uses a centered number mark inside an expanding starburst/orbit form. It is intentionally simple enough to remain recognizable at terminal-icon and social-card sizes.
