# Quickstart

```bash
git clone https://github.com/sanskarIN/guessnova.git
cd guessnova
python -m venv .venv
python -m pip install -e .
guessnova play
```

Try a daily challenge:

```bash
guessnova play --mode daily
```

Try the app-like terminal UI:

```bash
guessnova-tui
```

See saved performance:

```bash
guessnova stats
guessnova leaderboard
```
