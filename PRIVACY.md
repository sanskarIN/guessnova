# Privacy Policy

GuessNova is designed to work without an account and without sending gameplay data to a server.

## Data stored locally

The application may save profile names, settings, gameplay statistics, achievements, XP, streak values, and leaderboard entries in `state.json` under the local GuessNova data directory.

## Network behavior

The Python application itself does not require network access for gameplay and contains no telemetry, analytics, advertising, or remote-account code.

## Backups

The export command creates a local JSON backup chosen by the user. Import reads only the selected local file and validates the GuessNova export wrapper and schema version.

## Deletion

Users can delete their local GuessNova data directory at any time to remove saved application data.
